# NeuroGram

NeuroGram — Android-мессенджер с тёмным интерфейсом, красными неоновыми акцентами и минималистичным дизайном.

## Текущий статус

Сейчас в репозитории находится первая сборочная версия интерфейса:
- стартовый экран со списком демонстрационных чатов;
- экран просмотра выбранного чата;
- тёмная тема и адаптивная разметка на Jetpack Compose;
- GitHub Actions для автоматической сборки debug APK.

**Важно:** это пока UI-прототип. Регистрация, реальные сообщения между устройствами, загрузка фотографий, группы и онлайн-статусы ещё не подключены.

## Сборка APK

1. Открой вкладку **Actions** репозитория.
2. Выбери workflow **Build NeuroGram APK**.
3. Нажми **Run workflow** (или дождись автоматического запуска после push).
4. После успешной сборки открой запуск workflow и скачай artifact **NeuroGram-debug**.
5. Внутри artifact находится `app-debug.apk`.

## Технологии

- Kotlin
- Jetpack Compose
- Android Gradle Plugin
- GitHub Actions
